SISTEM PERPUSTAKAAN - JAVA OOP

File utama: Main.java

Cara menjalankan:
1. Pastikan JDK sudah terpasang.
2. Buka terminal di folder ini.
3. Kompilasi: javac Main.java
4. Jalankan: java Main

Fitur:
1. Tambah buku
2. Tambah majalah
3. Tampilkan semua koleksi
4. Cari koleksi berdasarkan judul
5. Urutkan berdasarkan tahun terbit
6. Pinjam koleksi
7. Kembalikan koleksi
0. Keluar

Materi OOP:
- Enum StatusKoleksi
- Interface DapatDipinjam
- Abstract class Koleksi
- Inheritance: Buku dan Majalah
- Polymorphism melalui List<Koleksi>
- Custom exceptions untuk peminjaman dan pengembalian
- Exception handling untuk input angka yang tidak valid
